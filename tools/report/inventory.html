About this inventory

This is a broad review pool, not a final inclusion list. It includes mathematical characters, printable ASCII, common Greek letters, and nearby blocks of symbols. A block may contain characters with no mathematical use.

Subheadings and notes come from NamesList. Character names, properties, block ranges, decompositions, scripts, formal aliases, and standardized variants come from their dedicated Unicode data files. A script value is not a language-independence verdict. Subheading labels are combined for browsing; their individual occurrences and notes remain attached to each character.

Glyphs use installed fonts. Combining marks are previewed with a dotted circle; copying returns the actual character without the circle. Invisible characters have a labeled preview.
